# Компоненты. JSX-Way.

Вот компонент продукта, который можно использовать через `<Product />`:
```js 
class Product extends Component {
    state = {
        storage: {},
        props: {},
    }

    buy() {
        alert('Вы успешно добавили в корзину товар!');
    }

    render() {
        return 
            <div className="card">
                <div className="card-header">{this.props.title}</div>
                <button onClick={this.buy}></button>
            </div>
        ;
    }
}
```
Вот компонент использующий компонент, который мы задекларировали выше:
```js 
class ProductsCatalog extends Component {
    props = {
        products: []
    }
    state = {}

    mount() {
        this.state.products = $wire.get('https://jsonplaceholder.typicode.com/products/')
    }

    render() {
        return 
            {this.props.products.map((product, index) => (
                <div key={product.id}>
                    <Product title={product.title} price={product.price} />
                </div>
            ))}
    }
}
```
И вот, собственно говоря, финальное использование в одну строчку:
```html 
<ProductCatalog products={[
    <Product title="FirstProduct" />,
    <Product title="SecondProduct" />,
    <Product title="ThirdProduct" />
]} />
```
