# Компоненты. 

Я долго думал как можно реализовать глубоковысокую систему проектирования. 
Смотрел в сторону Vue, увидел что сейчас библиотека как раз в этом русле течёт.
Посмотрел в сторону JSX\React. Понял что многих вещей оттуда не хватает.
И сел за перо. Проектировать. 

Вот компонент продукта, который можно использовать через `<product />`:
```js 
class Product extends Component {
    state = {
        storage: {}, // прямой доступ к синку со стореджем 
        props: {}, // прямой доступ к реактивным пропсам
    }

    events() { // тут обьявляются все доступные ивенты
        function buy() {
            alert('Вы успешно добавили в корзину товар!');
        }
    }

    render() { // рендер в стиле JSX но с сохранением темплейт-синтаксиса
        return html`
            <div class="card">
                <div class="card-header">{{ this.state.title }}</div>
                <button w-on="click:buy"></button>
            </div>
        `;
    }
}
```
Вот компонент использующий компонент, который мы задекларировали выше:
```js 
class ProductsCatalog extends Component {
    state = {
        products: []
    }

    mount() {
        this.state.products = $wire.get('https://jsonplaceholder.typicode.com/products/')
    }

    render() {
        return html`
            <div w-for="product,index in state.products traceby product.id">
                <product title="product.title" price="product.price"></product>
            </div>
        `;
    }
}
```
И вот, собственно говоря, финальное использование в одну строчку:
```html 
<product-catalog />
```

Плюсы:
- классовое разделение компонентов, нет мешанины 
- высокая переиспользуемость компонентов 
- класс и рендер похож на React, темплейт на Vue

Минусы:
- хрен привыкнешь, но со временем наладится
- в примере выше надо 2 джс файлика подключать прежде чем использовать финальный компонент `<product-catalog />`

Реализация:
- правка движка (ядра)
- добавление нового класса `Component`
- написание аутолоадера из коробки
