# API.

## Шаблонизация. 
- `w-transition` - устанавливает плавный переход между состояниями.
- `w-if="exp"` — показать или скрыть элемент в зависимости от условия. Элемент физически отсутствует в DOM когда условие ложно.
- `w-for="value,index in data traceby value.id"` — перебор массива. `value,index` без пробела внутри, `,index` необязателен. traceby указывает уникальный ключ для точечного обновления DOM.
- `w-class="{ 'active': !!isActive }"` — добавляет CSS-классы по условию. Принимает объект где ключ это класс, значение — условие.
- `w-bind="keyPath"` — двустороннее связывание для `input`, `select`, `textarea`. Пользователь вводит — стейт обновляется автоматически.
- `w-value="exp"` — одностороннее: из стейта в элемент. Только для `input`, `select`, `textarea`.
- `w-disabled="!!exp"` — блокирует элемент. Работает на `input`, `select`, `textarea`, `button`.
- `w-checked="!!exp"` — управляет `checked` для `input[type=checkbox]` и `input[type=radio]`.
- `w-selected="!!exp"` — управляет `selected` для `select` > `option`.
- `w-src="exp"` — устанавливает `src` у картинки после вставки в DOM. Всегда используйте вместо обычного `src` когда путь динамический.
- `w-on="event:fn"` — привязывает обработчик объявленный через `.fn()`.
- `w-static` — помечает блок как статический. Рендерится один раз и полностью выпадает из цикла перерисовки.
- `w-id="exp"` — присваивает виртуальному узлу стабильный идентификатор для точного патчинга при обновлениях.

## Хуки. 
- `$mount` — компонент появился на странице
- `$unmount` — компонент убран со страницы
- `$change` — стейт изменился
- `$render` — шаблон перерисован
- `$destroy` — компонент уничтожен
- `$route` — срабатывает при каждом изменении URL
- `$wiring` — срабатывает при использовании $wire
