# API

Справочник по всем публичным методам, директивам и хукам WEX.
Примеры и объяснения — в книге. `~/book/*` в корне репо.

---

# Глобальные функции

Доступны через `window.jqvm` после подключения CDN:

```js
const { component, directive, filter, shareState, createRouter, createAsyncComponent, View, useJQuery } = window.jqvm
```

- `component(name, view)` — зарегистрировать компонент глобально. Доступен во всех шаблонах страницы.
- `directive(name, compile, affect)` — зарегистрировать директиву глобально.
- `filter(name, formatter)` — зарегистрировать фильтр глобально.
- `shareState(initState)` — создать общий реактивный стейт для нескольких компонентов.
- `createRouter(options)` — создать экземпляр роутера. Принимает `{ mode: 'hash' | 'history' }`.
- `createAsyncComponent(loader, callback?)` — создать асинхронно загружаемый компонент. `loader` — функция возвращающая промис с вью. `callback` — вызывается после загрузки, `this` внутри — родительский вью.
- `useJQuery(jQuery)` — передать свою версию jQuery если нужна не та что висит на `window.$`.
- `View` — конструктор вью. Используется для проверки принадлежности: `myView instanceof View`.

# Создание вью

```js
const view = $(selector).state(initState)
const view = $(selector).vm(initState)  // полный алиас
```

`initState` — объект или функция возвращающая объект. Функция обязательна когда вью монтируется и демонтируется несколько раз — каждый `.mount()` получит независимую копию стейта.

Экземпляры классов (`new Something()`) передавать нельзя — только простые объекты.

# Методы вью

Все методы возвращают `view` и поддерживают цепочку.

## Жизненный цикл

- `.mount(el?)` — вставить вью в DOM. Без аргумента — после элемента-шаблона. С аргументом — внутрь указанного контейнера.
- `.unmount()` — убрать из DOM, сохранив все подписки. После `unmount()` можно снова вызвать `mount()`.
- `.destroy()` — убрать из DOM и очистить все подписки. После `destroy()` вью можно монтировать снова, но обработчики нужно навесить заново.
- `.update(nextState?)` — обновить стейт и перерендерить. Принимает объект (мерж), `true` (принудительный ре-рендер), или функцию `state => { ... }`.

## Поиск

- `.find(selector)` — найти элемент внутри контейнера вью. Аналог `$.fn.find`.

## Регистрация

- `.component(name, view)` — зарегистрировать компонент локально, только для этого шаблона.
- `.directive(name, compile, affect)` — зарегистрировать директиву локально.
- `.filter(name, formatter)` — зарегистрировать фильтр локально.
- `.plugin(plugin)` — подключить плагин. Используется для роутера.
- `.fn(name, handler)` — зарегистрировать именованную функцию. Нужна для `w-on` и компонентных событий `@`. Вызов с одним аргументом `.fn(name)` возвращает функцию по имени.

# Обработчики событий

- `.on(event, selector?, action)` — подписаться на событие.
- `.once(event, selector?, action)` — подписаться на событие, сработает только один раз.
- `.off(event, selector?, action)` — отписаться от события навешенного через `.on()`.

`action` — функция вида `function(state, ...args) { return function(e) { ... } }`.
Внешняя функция получает стейт. Внутренняя — необязательный обработчик DOM-события с доступом к `e` и `this`.

# Директивы шаблона

## Вывод и условия

- `{{ выражение }}` — интерполяция. Любое JavaScript-выражение.
- `w-if="exp"` — показать элемент если выражение истинно. Элемент физически отсутствует в DOM когда условие ложно.
- `w-for="value,index in data traceby value.id"` — перебор массива. `value,index` — без пробела внутри, `,index` необязателен. `traceby` — уникальный ключ для точечного обновления DOM, рекомендуется всегда указывать.
- `w-static` — пометить блок как статический. Рендерится один раз, полностью выпадает из цикла перерисовки. Необратимо.
- `w-id="exp"` — присвоить виртуальному узлу стабильный идентификатор для точного патчинга. Значение должно быть уникальным в пределах шаблона.

## Атрибуты и классы

- `w-class="{ 'className': exp }"` — добавлять CSS-классы по условию. Принимает объект где ключ — имя класса, значение — условие. Уживается с обычным атрибутом `class`.
- `w-src="exp"` — установить `src` у изображения после вставки в DOM. Всегда использовать вместо обычного `src` когда путь динамический.
- `w-transition` — плавный переход между состояниями элемента.

## Связывание полей

- `w-bind="keyPath"` — двустороннее связывание для `input`, `select`, `textarea`. Пользователь вводит — стейт обновляется, стейт меняется — поле обновляется.
- `w-value="exp"` — одностороннее: только из стейта в элемент. Для `input`, `select`, `textarea`.
- `w-disabled="exp"` — блокировать элемент если выражение истинно. Работает на `input`, `select`, `textarea`, `button`.
- `w-checked="exp"` — управлять `checked` для `input[type=checkbox]` и `input[type=radio]`.
- `w-selected="exp"` — управлять `selected` для `option` внутри `select`.

## События

- `w-on="event:fnName"` — привязать обработчик зарегистрированный через `.fn()`. Работает только в паре с ним.

## Роутер

- `w-route="'path'"` — показать блок если текущий URL совпадает с путём. Принимает строку или регулярное выражение. Значение — JavaScript-выражение, строки пишутся в кавычках внутри кавычек.
- `w-navigate="mode"` — перехватить навигацию по ссылке или кнопке. Режимы: `push`, `replace`, `back`, `forward`, `open`.

# Хуки жизненного цикла

Подписываются через `.on()`. Имя события начинается с `$`.

Хук      | Когда срабатывает                          | Типичное применение
---------|--------------------------------------------|-------------------------------------------
`$mount`   | Один раз, после вставки в DOM            | Загрузка данных, инициализация
`$unmount` | После удаления из DOM                    | Очистка таймеров, отписки
`$destroy` | После полного уничтожения                | Финальная очистка ресурсов
`$change`  | При каждом изменении стейта              | Слежение, синхронизация
`$render`  | После каждой перерисовки DOM             | Работа со сторонними библиотеками
`$route`   | При каждом изменении URL                 | Загрузка данных под новый маршрут
`$wiring`  | При использовании `$wire`                | Реакция на завершение wire-запроса

⚠ Внутри `$change` будьте осторожны с изменением стейта — это вызовет ещё один `$change`. Следите чтобы не получилась бесконечная цепочка.

# Хранилище (Store)

Ключ `storage` внутри стейта автоматически синхронизируется с `localStorage`.

```js
.state({
    nonPersistent: '',      // живёт только до перезагрузки
    storage: {
        persistent: '',     // сохраняется между сессиями
    }
})
```

- Данные сериализуются через `JSON.stringify` при записи и `JSON.parse` при чтении.
- Лимит `localStorage` — около 5 МБ на домен.
- Данные привязаны к домену и браузеру. В режиме инкогнито — не переносятся.

# Роутер

```js
const router = createRouter({ mode: 'hash' | 'history' })

$('#app').state({}).plugin(router).mount()
```

## Режимы

- `hash` — URL вида `site.ru/#/path`. Работает без настройки сервера.
- `history` — URL вида `site.ru/path`. Требует настройки сервера чтобы все пути возвращали один `index.html`.

## $router в стейте

После подключения плагина в стейте становится доступен объект `$router`:

- `$route.params` — текущие query-параметры URL, доступны прямо в шаблоне.
- `$router.getLocation()` — получить текущий путь и параметры.
- `$router.setParams(params)` — обновить query-параметры без перезагрузки.

# Пропсы компонента

Передаются как атрибуты HTML-тега. Работают только те ключи, которые объявлены в стейте компонента.

- `prop="value"` — строка.
- `:prop="exp"` — выражение из стейта родителя.
- `@event="fnName"` — подписаться на `emit` компонента. Обработчик регистрируется через `.fn()` на родительском вью.

## Эмиттер

- `this.emit(event, ...args)` — вызвать событие из компонента. Родитель подписывается через `@event`.

# Директивы — создание своих

```js
directive(name, compile, affect)
```

- `compile($el, attrs)` — вызывается на стадии построения виртуального дерева. `$el` — виртуальная копия. Можно изменять атрибуты или вернуть строку чтобы заменить элемент целиком.
- `affect($el, attrs)` — вызывается после вставки в реальный DOM. Здесь вешают события и инициализируют плагины. Верните функцию-очистку — WEX вызовет её перед следующим рендером.

Внутри `affect` доступно `this.scope.interpolate(str)` для раскрытия `{{ }}` в строке значения атрибута.

# Фильтры

```
{{ выражение | фильтр }}
{{ выражение | фильтр:аргумент }}
{{ выражение | фильтр1 | фильтр2 }}
```

Регистрация локально через `.filter(name, fn)` на вью или глобально через `filter(name, fn)` из импорта.

`fn(value, ...args)` — принимает значение и необязательные аргументы через `:`. Возвращает отформатированную строку. Не изменяет стейт.
