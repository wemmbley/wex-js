# Встроенный роутер

Прежде чем разбирать API — нужно понять саму идею. 

Когда пользователь переходит по ссылке на обычном сайте, браузер загружает новую 
страницу целиком. Роутер в WEX перехватывает эту навигацию и говорит браузеру: 
«не перезагружай страницу, я сам разберусь что показать». Адресная строка меняется, 
кнопка «назад» работает — но страница не перезагружается. Это и есть клиентский роутинг.

Под капотом роутер переписывает нативные `history.pushState` и `history.replaceState`, 
слушает `popstate` — и при любом изменении URL уведомляет вью чтобы та перерисовалась 
с учётом нового адреса.

## Подключение
Роутер подключается как плагин через `.plugin()`:
```js 
const { createRouter } = window.jqvm

const router = createRouter({ mode: 'hash' }) // или 'history'

$('#app')
  .state()
  .plugin(router)
  .mount()
```

## Два режима работы:
### hash-режим 
URL выглядит как site.ru/#/catalog. 
Работает везде без настройки сервера. 
Хэш-часть никогда не отправляется на сервер, роутер читает её сам.

### history-режим 
URL выглядит как site.ru/catalog. 
Красиво, но требует настройки сервера чтобы все пути возвращали 
один и тот же index.html. На Apache или Nginx это пара строк в конфиге.

## w-route — показать блок для конкретного маршрута
Это директива-аналог `w-if`, но условие — текущий URL а не стейт:

```html 
<template id="app">
    <nav>
        <a href="#/" w-navigate="push">Главная</a>
        <a href="#/catalog" w-navigate="push">Каталог</a>
        <a href="#/about" w-navigate="push">О нас</a>
    </nav>

    <div w-route="'/'">
        <h1>Добро пожаловать!</h1>
        <p>Это главная страница.</p>
    </div>

    <div w-route="'/catalog'">
        <h1>Каталог товаров</h1>
    </div>

    <div w-route="'/about'">
        <h1>О нас</h1>
    </div>
</template>

<script>
    $('#app').state().mount()
</script>
```

Заметьте: значение `w-route` — это выражение, поэтому строки пишутся 
в кавычках внутри кавычек: `w-route="'/catalog'"`.

## w-navigate — умные ссылки
Обычный `<a href>` вызовет полную перезагрузку страницы. `w-navigate` перехватывает клик 
и передаёт навигацию роутеру:

```html 
<!-- push — добавляет в историю (можно вернуться назад) -->
<a href="#/catalog" w-navigate="push">Каталог</a>

<!-- replace — заменяет текущую запись в истории -->
<a href="#/login" w-navigate="replace">Войти</a>

<!-- back / forward — как кнопки браузера -->
<button w-navigate="back">← Назад</button>
<button w-navigate="forward">Вперёд →</button>

<!-- open — новая вкладка -->
<a href="https://google.com" w-navigate="open">Открыть</a>
```

## Параметры в URL

Роутер умеет читать query-параметры из адресной строки — удобно для фильтров, 
страниц пагинации, ID записей:
```html 
<template id="app">
    <div w-route="'/catalog'">
        <p>Категория: {{ $route.params.category }}</p>
        <p>Страница: {{ $route.params.page }}</p>
        <button class="next-btn">Следующая страница</button>
    </div>
</template>

<script >
    const { createRouter } = window.jqvm
    const router = createRouter({ mode: 'hash' })

    $('#app')
        .state()
        .plugin(router)
        .fn('nextPage', function() {
            const { $router } = this
            return () => {
                const { params } = $router.getLocation()
                const current = parseInt(params.page) || 1
                $router.setParams({ page: current + 1 })
            }
        })
        .on('click', '.next-btn', function(state) {
            return this.fn('nextPage')(state)
        })
        .mount()
</script>
```

URL станет `#/catalog?category=shoes&page=2`. 
`$route.params` доступен прямо в шаблоне как часть стейта.

## Регулярные выражения в маршрутах

Для гибкого матчинга — например показать один блок для любой страницы 
товара — можно использовать регулярки:
```html 
<!-- Сработает для /product/1, /product/42, /product/anything -->
<div w-route="/^\/product\/.+/">
    <h1>Страница товара</h1>
</div>
```

## Реакция на смену маршрута

Хук `$route` срабатывает при каждом изменении URL — 
удобно для загрузки данных под новый маршрут:
```js 
$('#app')
  .vm({ products: [], loading: false })
  .plugin(router)
  .on('$route', (state, url) => {
      if (url === '/catalog') {
          state.loading = true
          $.get('/api/products').then(data => {
              state.products = data
              state.loading = false
          })
      }
  })
  .mount()
```
