# Модалки

Из коробки никаких модалок не предусмотрено. Но есть глубокая интеграция с Bootstrap 5.
Для этого мы должны сперва подключить саму библиотеку Bootstrap и дальше начать пользоваться
хелперами Wex.

## 🔌⚡ Подключение.

Здесь нам понадобиться лишь файл стилей и сам бутстрап.

```html 
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.2.3/dist/css/bootstrap.min.css" rel="stylesheet">
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.2.3/dist/js/bootstrap.bundle.min.js"></script>
```

После этого не забудьте в сторогой последовательности подключить сперва `jQuery`, а потом и сам `Wex`.

## Механизм.

Есть два принципиально отличных друг от друга механизма работы с модалками в Wex.

### Императивный подход в стиле jQuery Bootstrap 4

Первай механизм самый простой, state-independency (независимый от стейта), он же Bootstrap 4-like,
то есть по образу и подобию сделан как в BS4, пока из него не выпилили jQuery.

```js 
$('#simpleModal').modal('show')
$('#simpleModal').modal('hide')
$('#simpleModal').modal('toggle')
```

То есть мы буквально подключаемся к модалке через jQuery и используем старый синтаксис модалок. 

### Декларативный подход в стиле Wex.

```html 
<template id="app">
    <button class="btn btn-primary" w-modal="myModal">Toggle myModal</button>
</template>

<div id="myModal" class="modal fade" tabindex="-1">
    <div class="modal-dialog"><div class="modal-content">
        <div class="modal-header">
            <h5 class="modal-title">Моя модалка</h5>
            <button type="button" class="btn-close" data-bs-dismiss="modal"></button>
        </div>
        <div class="modal-body">Просто контент</div>
    </div></div>
</div>
```
```js 
$('#app')
    .state({
        modal: {
            myModal: false,
        }
    })
    .mount()
```

Здесь в чём фишка. Идёт глубокая интеграция со стейтом Wex. Флаг `state.modal.myModal`
реактивно отражает состояние модалки. 

Теперь по нюансам обязатальным:
- Кнопка должна иметь специальный тег `w-modal`, а значение этого тега - `id` модалки!
- Стейт обязан иметь вкладку `modal`, это хранилище всех модалок!
- Внутри хранилища модалок Вы обязаны указать айдишник Вашей модалки из `w-modal`! 

### Разница императивного и декларативного подходов

Разница в том, что в декларативном подходе у Вас всего одна строчка кода. 
Вот она. `$('#simpleModal').modal('toggle')`. Вам нет необходимости 
разворачивать целый стейт Wex как во втором случае, но этот самый стейт 
Вы и теряете.

Во втором же случае, идёт плотная интеграция со стейтом, но есть необходимость
заведомо прописать чёткий `state` по правилам, прописать конкретный айдишник
модалке и указать его в `w-modal` кнопки, эту самую модалку открывающей.

## Хуки

| Имя          | Параметры           | Предназначение                   |
|--------------|-------------------|---------------------------------|
| `$modalShown` | `(state, modalKey)` | Вызывается когда показана модалка |
| `$modalHidden` | `(state, modalKey)` | Вызывается когда модалка скрывается |
