# Фильтры

Представьте что в стейте лежит число `1990.5`.
Вывести его напрямую через `{{ price }}` — получите `1990.5`. Но пользователю хочется 
показать `1 990,50 $`. Можно написать функцию форматирования и вызывать 
её везде вручную — но это быстро превращается в повторяющийся код раскиданный 
по всему шаблону.

Фильтр — это функция-форматировщик которая применяется прямо 
в шаблоне через символ `|`. Один раз описали правило преобразования — 
используете везде одной строкой.

```html 
<div>{{ price | number:2 }}</div>
```

```js 
view.filter('number', function(value, fixed) {
    return value.toFixed(fixed)
})
```

Читается как «возьми price и прогони через фильтр number с аргументом 2».

## Реальные кейсы

### Форматирование цены. 

Самый частый случай — привести число к красивому денежному виду:
```html 
<template id="app">
    <p>Цена: {{ price | currency }}</p>
    <p>Скидка: {{ oldPrice | currency }}</p>
</template>

<script>
    $('#app')
            .state({ price: 1990.5, oldPrice: 2500 })
            .filter('currency', function(value) {
                return value.toLocaleString('ru-RU', {
                    style: 'currency',
                    currency: 'RUB'
                })
            })
            .mount()

    // Выведет: 1 990,50 ₽ и 2 500,00 ₽
</script>
```

### Дата в человекочитаемом виде. 

Из базы данных обычно приходит строка вроде `2024-03-15T10:30:00` — 
пользователю это показывать не стоит:
```html 
<template id="app">
    <div w-for="post in posts traceby post.id">
        <h3>{{ post.title }}</h3>
        <span>{{ post.createdAt | date }}</span>
    </div>
</template>

<script>
    $('#app')
        .state({
            posts: [
                { id: 1, title: 'Первая статья', createdAt: '2024-03-15T10:30:00' },
                { id: 2, title: 'Вторая статья', createdAt: '2024-01-22T08:00:00' },
            ]
        })
        .filter('date', function(value) {
            return new Date(value).toLocaleDateString('ru-RU', {
                day: 'numeric',
                month: 'long',
                year: 'numeric'
            })
        })
        .mount()

    // Выведет: 15 марта 2024 г. и 22 января 2024 г.
</script>
```

### Обрезка длинного текста. 
Для карточек и превью часто нужно ограничить количество символов:
```html 
<template id="app">
    <div w-for="article in articles traceby article.id">
        <h3>{{ article.title }}</h3>
        <p>{{ article.body | truncate:120 }}</p>
    </div>
</template>

<script>
    $('#app')
        .state({ articles: [...] })
        .filter('truncate', function(value, limit) {
            if (value.length <= limit) return value
            return value.slice(0, limit).trimEnd() + '...'
        })
        .mount()
</script>
```

### Множественное число. 
Классическая задача — «1 товар», «2 товара», «5 товаров»:
```html 
<template id="app">
    <p>{{ count }} {{ count | plural:'товар,товара,товаров' }}</p>
</template>

<script>
    $('#app')
        .state({ count: 0 })
        .filter('plural', function(value, words) {
            const [one, few, many] = words.split(',')
            const mod10 = value % 10
            const mod100 = value % 100

            if (mod100 >= 11 && mod100 <= 19) return many
            if (mod10 === 1) return one
            if (mod10 >= 2 && mod10 <= 4) return few
            return many
        })
        .mount()

    // 1 товар, 3 товара, 11 товаров, 21 товар
</script>
```

## Цепочка фильтров

Фильтры можно применять последовательно — результат одного передаётся в следующий:
```html 
<template id="app">
    <p>{{ comment | truncate:80 | uppercase }}</p>
</template>

<script>
    $('#app')
        .state({ comment: 'очень длинный комментарий пользователя...' })
        .filter('truncate', function(value, limit) {
            return value.length > limit ? value.slice(0, limit) + '...' : value
        })
        .filter('uppercase', function(value) {
            return value.toUpperCase()
        })
        .mount()
</script>
```
Сначала обрежется до 80 символов, затем переведётся в верхний регистр.

## Глобальные фильтры

Если фильтр нужен по всему приложению — регистрируйте его глобально 
через импорт, чтобы не повторять в каждом шаблоне:

```js 
const { filter } = window.jqvm

filter('currency', function(value) {
    return value.toLocaleString('ru-RU', {
        style: 'currency',
        currency: 'RUB'
    })
})

filter('date', function(value) {
    return new Date(value).toLocaleDateString('ru-RU')
})

// Теперь {{ price | currency }} и {{ date | date }}
// работают в любом шаблоне на странице
```

## Когда фильтр, а когда вычисление в стейте

Фильтры — для отображения. Они не меняют исходные данные в стейте, 
только форматируют их на лету при выводе. Если вам нужно именно 
изменить данные и работать с ними дальше в логике — 
делайте это в стейте или в обработчике.

```js 
// ✓ Фильтр — только для показа, данные в стейте остаются числом
{{ price | currency }}   // в стейте: 1990.5, на экране: 1 990,50 ₽

// ✓ Вычисление в стейте — когда результат нужен в логике
state.total = state.items.reduce((sum, item) => sum + item.price, 0)
```

Хорошее правило: если задача «показать красиво» — фильтр. 
Если задача «посчитать и использовать» — стейт.
