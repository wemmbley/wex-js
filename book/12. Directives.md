# Свои директивы.

Директивы — это пользовательские атрибуты которые WEX умеет обрабатывать 
при компиляции шаблона. Если встроенных директив не хватает — вы создаёте свои. 
Нужен атрибут `w-tooltip`, `w-animate`, `w-permission`? — директива именно для этого.

```js 
directive(name, compile, affect)
```

Два этапа обработки: `compile` — на стадии построения виртуального дерева, 
`affect` — когда элемент уже в реальном DOM.

## compile — изменить разметку до вставки в DOM

Вызывается когда WEX встречает ваш атрибут при компиляции шаблона. 
Элемент здесь виртуальный — его ещё нет на странице. Можно менять атрибуты, 
заменять содержимое, возвращать новый HTML.

```js 
const { directive } = window.jqvm

directive('w-link', function($el, attrs) {
    const link = attrs['w-link']
    $el.attr('href', link)
    // ничего не возвращаем — $el используется как есть
})
```
```html 
<template id="app">
    <a w-link="https://example.com">Ссылка</a>
</template>
```

Если вернуть строку — она заменит весь элемент:
```js 
directive('w-badge', function($el, attrs) {
    const count = attrs['w-badge']
    return `<span class="badge">${count}</span>`
    // оригинальный элемент заменён новым
})
```

⚠ `$el` в `compile` — это копия, не реальный DOM-элемент. 
Навешивать события здесь бессмысленно — они не сработают.

## affect — работать с реальным DOM

Вызывается после того как всё дерево скомпилировано и вставлено на страницу. 
Здесь `$el` — настоящий живой элемент. Можно вешать события, инициализировать плагины, читать размеры.
```js 
directive('w-src', null, function($el, attrs) {
    // this.scope.interpolate раскрывает {{ }} внутри значения
    const value = this.scope.interpolate(attrs['w-src'])
    $el.attr('src', value)
})
```
```html 
<img w-src="/images/{{user.avatar}}.jpg">
```
Это исходник встроенного `w-src` — именно так картинка не пытается загрузиться 
по буквальной строке `{{ user.avatar }}` во время компиляции.

## Очистка побочных эффектов

Если в `affect` вы вешаете обработчики или запускаете интервалы — верните функцию-очистку. 
WEX вызовет её перед каждым следующим рендером:

```js 
directive('w-click-outside', null, function($el, attrs) {
    const handler = (e) => {
        if (!$el[0].contains(e.target)) {
            $el.trigger('clickOutside')
        }
    }

    $(document).on('click', handler)

    return () => $(document).off('click', handler)
    // ↑ обязательно — иначе при каждом ре-рендере
    //   будет вешаться новый обработчик
})
```

Пример с инициализацией стороннего плагина:
```js 
directive('w-datepicker', null, function($el, attrs) {
    const picker = $el.datepicker({ format: attrs['w-datepicker'] || 'dd.mm.yyyy' })

    return () => picker.datepicker('destroy')
})
```
```html 
<input w-datepicker="yyyy-mm-dd">
```

## Локальная директива — только для одного шаблона

Глобальная директива через `window.state` работает во всех шаблонах страницы. 
Если директива нужна только в одном месте — регистрируйте её прямо на вью:
```js 
// глобально — доступна везде
const { directive } = window.jqvm
directive('w-highlight', ...)

// локально — только для этого шаблона
$('#app')
  .state({ ... })
  .directive('w-highlight', null, function($el, attrs) {
      $el.css('background', attrs['w-highlight'] || 'yellow')
  })
  .mount()
```

## Встроенные директивы

WEX поставляется с набором готовых директив. 
Все они работают по тем же правилам что описаны выше — просто уже написаны за вас.

- `w-if="!!exp"` — показать или скрыть элемент в зависимости от условия. Элемент физически отсутствует в DOM когда условие ложно.
- `w-for="value,index in data traceby value.id"` — перебор массива. `value,index` без пробела внутри, `,index` необязателен. traceby указывает уникальный ключ для точечного обновления DOM.
- `w-class="{ 'active': !!isActive }"` — добавляет CSS-классы по условию. Принимает объект где ключ это класс, значение — условие.
- `w-bind="keyPath"` — двустороннее связывание для `input`, `select`, `textarea`. Пользователь вводит — стейт обновляется автоматически.
- `w-value="exp"` — одностороннее: из стейта в элемент. Только для `input`, `select`, `textarea`.
- `w-disabled="!!exp"` — блокирует элемент. Работает на `input`, `select`, `textarea`, `button`.
- `w-checked="!!exp"` — управляет `checked` для `input[type=checkbox]` и `input[type=radio]`.
- `w-selected="!!exp"` — управляет `selected` для `select` > `option`.
- `w-src="exp"` — устанавливает `src` у картинки после вставки в DOM. Всегда используйте вместо обычного `src` когда путь динамический.
- `w-on="event:fn"` — привязывает обработчик объявленный через `.fn()`. Работает в паре с ним:
```html 
<button w-on="click:handleSubmit">Отправить</button>
```
```js 
$('#app')
  .state({})
  .fn('handleSubmit', state => function(e) {
      // обработчик
  })
  .mount()
```
- `w-static` — помечает блок как статический. Рендерится один раз и полностью выпадает из цикла перерисовки.
- `w-id="exp"` — присваивает виртуальному узлу стабильный идентификатор для точного патчинга при обновлениях.
