# Хранилище (Store)

Представьте что пользователь набрал очки в игре, заполнил форму 
или выбрал тему оформления — и вдруг обновил страницу. 
Всё сбросилось. Стейт WEX живёт только в памяти браузера, 
и при перезагрузке возвращается к начальным значениям.
Чтобы этого не происходило, в WEX есть встроенный механизм сохранения — Store. 

Достаточно положить нужные данные в специальный ключ стейта с именем storage, 
и фреймворк автоматически будет синхронизировать их с localStorage браузера. 
Данные переживут перезагрузку, закрытие вкладки и возврат на страницу.

```html 
<template id="score">
    <p>Score: {{ storage.score }}</p>
    <button class="increase-btn">Increase</button>
</template>

<script>
    $('#score')
        .state({
            storage: {
                score: 0,
                test: 1,
            }
        })
        .on('click', '.increase-btn', state => {
            state.storage.score = ++state.storage.score;
        })
        .mount()
</script>
```

Всё что находится внутри `storage` — сохраняется. Всё что снаружи — 
живёт только до перезагрузки. Это намеренное разделение: 
вы сами решаете что важно сохранить, а что нет.

## Что происходит под капотом

WEX следит за `storage` в двух точках жизненного цикла:

При монтировании (`$mount`) — фреймворк смотрит есть ли в `localStorage` 
сохранённые значения для каждого ключа из `storage`. Если есть — загружает 
их в стейт, и пользователь видит свои прошлые данные. Если нет — записывает 
текущие начальные значения как точку отсчёта.

При каждом изменении стейта (`$change`) — если данные в `storage` изменились, 
они немедленно записываются в `localStorage`. Синхронизация происходит автоматически, 
вам не нужно ничего вызывать вручную.

```
Первый визит:          Повторный визит:
-------------------------------------------------
storage.score = 0      localStorage → score = "7"
```

## Что хранить в storage
Store хорошо подходит для данных которые должны пережить перезагрузку:
- счётчики и прогресс
- выбранный язык или тема оформления
- содержимое корзины
- состояние формы которую пользователь не дозаполнил
- любые пользовательские настройки

```js 
$('#app')
    .state({
        theme: 'light',       // ← не сохранится
        username: '',         // ← не сохранится
        storage: {
            lang: 'ru',       // ← сохранится
            fontSize: 16,     // ← сохранится
            darkMode: false,  // ← сохранится
        }
    })
    .mount()
```

## Важно знать!
⚠ localStorage хранит только строки. WEX автоматически сериализует 
значения через JSON.stringify при записи и JSON.parse при чтении. 
Это означает что числа, булевы значения и вложенные объекты работают 
корректно — но при чтении из пустого хранилища всегда проверяйте 
что значение не null.

⚠ localStorage ограничен объёмом около 5 МБ на домен. 
Для хранения больших массивов данных или файлов он 
не подходит — держите в storage только лёгкие настройки и счётчики.

⚠ Данные в localStorage привязаны к домену и браузеру. 
Если пользователь откроет сайт в другом браузере или 
режиме инкогнито — история не перенесётся.
